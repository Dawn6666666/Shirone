## 1. Markdown 与 MDX 功能对比矩阵

| 功能特性 | 标准 Markdown | Shirone MDX | 执行模式 |
| :--- | :--- | :--- | :--- |
| **排版与基础结构** | 完整支持 | 完整支持 | 静态 SSR |
| **代码块高亮** | 行号、边框、折叠 | 行号、边框、折叠 | Expressive Code 静态 SSR |
| **图表与数学公式** | Mermaid, KaTeX | Mermaid, KaTeX | 客户端动态增强 |
| **提示块** | Note, Tip, Important, Warning, Caution | Note, Tip, Important, Warning, Caution | 静态 SSR |
| **M3E 展示原子组件** | 不支持 | 直接集成 | 纯 SSR |
| **Svelte 5 响应式孤岛** | 不支持 | 按需动态水合 | `client:visible` 懒加载水合 |
| **反馈与加载原子** | 不支持 | 形状形变动画 | `client:visible` 响应式运行 |
| **动态 JSX 表达式** | 不支持 | 原生计算求值 | 编译期或客户端动态求值 |
